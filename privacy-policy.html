Privacy Policy

Effective date: June 28, 2026

We collect only what's needed. We never sell your data.

📋

Overview

This Privacy Policy explains what data Letterboxd Tracker Bot ("the Bot", "we", "our") collects when you add it to a Discord server or interact with its commands, how that data is used, how long it is kept, and what controls you have over it. We are committed to collecting only the minimum data necessary to operate the Bot's features.

📥

Data We Collect

All data is stored in a private SQLite database. Here is exactly what is stored and why:

Server (Guild) Configuration

  • ▸ Discord Guild ID and the date the Bot joined
  • ▸ Channel IDs you configure for diary posts and commands
  • ▸ Custom embed colour, timezone, ping role, and a Discord invite link you optionally set
  • ▸ Diary and film embed display toggles, custom label names, and timestamp style
  • ▸ Anonymity / privacy toggles (whether your server name and tracked usernames appear in global stats)
  • ▸ Recap schedule and quiet-hours preferences
  • ▸ Permission group assignments and per-command overrides (admin / mod / user)

Purpose: To deliver diary posts and responses to the correct channels with your chosen settings.

Tracked Letterboxd Usernames

  • ▸ Letterboxd usernames added via /adduser, the guild ID they belong to, and when they were added
  • ▸ The Discord User ID of who added the user, and the Discord member linked to each tracked username
  • ▸ Per-username polling state (last activity time, next check time, failure counts) used for adaptive scheduling

Purpose: To know which Letterboxd accounts to poll and where to post new diary entries.

Diary Entry Activity

  • ▸ IDs of diary entries that have already been posted, stored for 14 days to prevent duplicate posts
  • ▸ Per-entry statistics (film title, slug, year, TMDB ID, rating, liked, rewatch flag, watched date, primary genre, director, username, guild ID) used for /stats, /compare and /recap
  • ▸ Backfilled film history scraped from each tracked user's public Letterboxd profile, used to power statistics and filters
  • ▸ Full diary entry JSON temporarily stored for failed-post retries, automatically deleted after 7 days if the post cannot be delivered

Purpose: Deduplication, server statistics, filters, and reliable delivery via retry.

User Preferences

  • ▸ A per-user timezone preference set via /timezone (defaults to UTC)

Purpose: Displaying timestamps in your local time.

Settings Audit Log

  • ▸ A log of admin setting changes, including: guild ID, the Discord User ID and display name of who made the change, the setting name, old value, new value, and timestamp. Entries are automatically deleted after 90 days.

Purpose: Allows server admins to audit configuration changes via /auditlog.

Command Usage Statistics

  • ▸ Guild ID, command name, Discord User ID, and timestamp for each command invocation

Purpose: Internal analytics to understand feature usage and improve the Bot. This data is not shared externally.

TMDB Cache

  • ▸ Film metadata from The Movie Database (TMDB): title, year, poster & backdrop URLs, director, genres, runtime, overview, language, country, tagline, cast, and TMDB vote averages

Purpose: Reduces redundant calls to the TMDB API. Cached metadata is refreshed periodically. No personal data is involved.

🚫

What We Do NOT Collect

  • ▸ Message content or conversation history from your Discord server.
  • ▸ Passwords, authentication tokens, or any credentials.
  • ▸ Private Letterboxd account data - only publicly visible diary entries and profiles are accessed.
  • ▸ IP addresses or device information.
  • ▸ Payment or financial data of any kind.
  • ▸ Email addresses.
🔗

External Services We Contact

The Bot communicates with the following external services to function. All connections are over HTTPS.

Letterboxd.com

The Bot reads each tracked user's public Letterboxd RSS diary feed to check for new entries, and scrapes public profile pages for film history, watchlists, and lists. It sends only the Letterboxd username and receives publicly available data (film title, rating, like, rewatch flag, review text, watched date). No authentication credentials are sent. The Bot retries failed requests with backoff and respects rate-limit (HTTP 429) responses.

TMDB (The Movie Database)

Film titles are sent to the TMDB API to retrieve metadata such as posters, synopsis, cast, director, genres, runtime, and ratings. Results are cached to minimise repeated calls. This product uses the TMDB API but is not endorsed or certified by TMDB.

Discord API

All standard Discord bot communication is performed through Discord's official API in accordance with Discord's Privacy Policy.

Developer Monitoring

To keep the Bot running smoothly, the developer receives automated alerts for things like servers joining or leaving, users being added or removed, API errors, and rate-limit warnings. These include basic info such as server name and member count. This data is used only for operational health checks and is never shared with anyone.

🗂️

Data Retention

7

Days - Failed Post Retry Buffer

Diary entries that couldn't be delivered are held for up to 7 days while the bot retries, then automatically deleted.

14

Days - Seen Entries

Diary entry IDs used for duplicate detection are purged after 14 days.

90

Days - Settings Audit Log

Settings audit log entries are automatically deleted after 90 days.

90

Days - TMDB Film Cache & Search Cache

Cached TMDB film metadata is purged after 90 days, and the film search cache after 30 days. Frequently looked-up films stay cached while in use. Contains no personal data.

48h

Hours - After Bot Removal

All data associated with a server (tracked usernames, settings, stats, audit logs, etc.) is permanently and automatically deleted 48 hours after the Bot is removed from that server.

∞

Indefinite - While Bot is Active

Guild configuration, role settings, tracked usernames, film history/stats, user preferences, and command usage statistics are kept for as long as the Bot remains in your server.

Your Privacy Controls

The following built-in commands give you control over your data:

/listusers

Lists all Letterboxd usernames currently being tracked in your server.

/removeuser

Removes a Letterboxd username from tracking. Associated seen-entry records are deleted.

/settings

Open the configuration panel to toggle anonymity / privacy options, such as hiding your server name or tracked usernames from global statistics.

/auditlog

Review the recent history of admin setting changes for your server.

/timezone

Sets your personal timezone preference. You can change it at any time.

To request complete deletion of all data for your server, simply remove the Bot - all data will be purged within 48 hours. For individual data deletion requests or any other privacy concern, contact us via our support server.

📊

Global Statistics

The /stats command can display global statistics aggregated across all servers using the Bot, such as total tracked users and trending films. Server names are hidden in global stats by default; tracked usernames may appear unless you hide them. You can control your server's participation and these privacy toggles in /settings. Any usernames or activity shown reflect publicly available Letterboxd data.

🔐

Security Practices

  • ▸ All external API requests use HTTPS with compression where available.
  • ▸ The database uses prepared statements to prevent SQL injection.
  • ▸ The database uses WAL (Write-Ahead Logging) mode with automatic rollbacks on errors.
  • ▸ Rate limiting is enforced per-user, per-guild, and globally to protect against abuse.
  • ▸ A circuit-breaker system prevents cascading failures from API outages.
  • ▸ Sensitive configuration (tokens, webhook URLs, API keys) is stored as environment variables, never in the database.
